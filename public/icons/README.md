# PWA icons

Place the following files here before shipping installable PWA support:

| File                   | Size               |
| ---------------------- | ------------------ |
| `icon-192.png`         | 192×192            |
| `icon-512.png`         | 512×512            |
| `apple-touch-icon.png` | 180×180 (optional) |

Referenced by `src/app/manifest.ts` and root layout metadata.

Generate icons from your brand asset using tools such as [PWA Asset Generator](https://github.com/elegantapp/pwa-asset-generator).
